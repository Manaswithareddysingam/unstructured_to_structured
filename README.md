# Intelligent Data-to-Action

Demo repo for Intelligent Data→Action system (Colab demo included).

## Files:
- main.py (FastAPI stub)
- actions.py (action handlers)
- demo.ipynb (Colab notebook)
- requirements.txt

## How to run:

1. Install dependencies:
2. Run the API locally:
3. Use endpoints:
- `/create_task` (text input)
- `/create_invoice` (image input)
- `/create_note` (text input)
- `/create_issue` (text input)

## Demo:
Open `demo.ipynb` and run cells in order to see the pipeline in action.
